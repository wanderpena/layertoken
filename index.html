Why LayerToken?

Modern CSS features with zero build step

🎯

Token-First Design

Centralized design tokens using CSS Custom Properties. Change your entire theme by updating a few variables. No compilation needed.

📦

Layer Architecture

Predictable cascade using CSS @layer. No more specificity wars or !important hacks. Clean, maintainable code.

🌓

Dark Mode Built-in

Automatic dark mode detection with manual override. Runtime theme switching without page reloads. 7 preset themes included.

📱

Container Queries

Components that respond to their container width, not viewport. True component encapsulation and reusability.

⚡

Zero JavaScript

Pure CSS with modern browser features. No build step, no dependencies, no runtime overhead. Just link and go.

♿

Accessible

WCAG 2.1 AA compliant. Respects user preferences for reduced motion and high contrast. Semantic HTML throughout.

Quick Start

Get up and running in 60 seconds

1. Include CSS

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/wanderpena/layertoken@main/layertoken.css">

2. Start Building

<div class="container-5xl"> <h1 class="text-4xl font-bold">Hello LayerToken!</h1> <button class="btn btn-primary">Get Started</button> </div>

3. Customize (Optional)

<style> :root { --color-primary-h: 280; /* Purple */ --space-unit: 0.5rem; /* Larger spacing */ } </style>
